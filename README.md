# PulsePDFsign — public site

Hosts the privacy policy for **PulsePDFsign**, the Windows application for
signing PDF documents with PAdES signatures.

- Privacy policy: https://fokionpapanikolaou.github.io/PulsePDFsign-Tool/

The application's source lives in a separate, private repository. This one
exists only so the policy has a public address, which the Microsoft Store
requires.
